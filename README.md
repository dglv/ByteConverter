# ByteConverter
Byte converter written on Python

## Install and run
### Windows:
```bash
# Activate environment
> python -m venv venv
> .\venv\Scripts\activate
(venv)> pip install -r .\requirements.txt

# Deactivate environment
(venv)> deactivate
```

### Linux:
```bash
# Activate environment
$ python3 -m venv .venv
$ source .venv/bin/activate
(.venv)$ pip install -r requirements.txt

# Deactivate environment
(.venv)$ deactivate
```
