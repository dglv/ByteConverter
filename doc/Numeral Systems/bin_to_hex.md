# Перевод из двоичной системы счисления в шестнадцатеричную

Разбиваем число на группы по 4 цифры. Последнюю (левую) группу дополним при необходимости ведущими нулями. 
Заменим полученные группы (тетрады) на соответствующие цифры шестнадцатеричной системы, используя таблицу тетрад:

| Тетрада | Цифра |
|:-------:|:-----:|
|  0000   |   0   | 
|  0001   |   1   |
|  0010   |   2   |
|  0011   |   3   |
|  0100   |   4   | 
|  0101   |   5   |
|  0110   |   6   |
|  0111   |   7   |
|  1000   |   8   | 
|  1001   |   9   |
|  1010   |   A   |
|  1011   |   B   |
|  1100   |   C   |
|  1101   |   D   |
|  1110   |   E   |
|  1111   |   F   |

## Примеры
```text
101111100 (2)       -> (0001) (0111) (1100) = 17C (16)
10101010 (2)        -> (1010) (1010) = (10) (10) = AA (16)
010101 (2)          -> (0001) (0101) = (1) (5) = 15 (16)
```
