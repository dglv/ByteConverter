# Перевод в десятичную систему счисления

Преобразовать число из любой системы счисления в десятичную можно следующим образом: 
Каждый разряд числа необходимо умножить на X^n, где X - основание исходного числа, n - номер разряда. Затем суммировать полученные значения.

```text
abc (x) = a * x^2 + b * x^1 + c * x^0 (10)
```

## Примеры
```text
1 (8) 			= 1 * 8^0 = 1 (10)
111 (8)			= 1 * 8^2 + 1 * 8^1 + 1 * 8^0 = 64 + 8 + 1 = 73 (10)
A9 (16)			= 10 * 16^1 + 9 * 16^0 = 160 + 9 = 169 (10)
FF (16)			= 15 * 16^1 + 15 * 16^0 = 240 + 15 = 255 (10)
10110010 (2)	= 1 * 2^7 + 0 * 2^6 + 1 * 2^5 + 1 * 2^4 + 0 * 2^3 + 0 * 2^2 + 1 * 2^1 + 0 * 2^0 = 128 + 0 + 32 + 16 + 0 + 0 + 2 + 0 = 178 (10)
```
